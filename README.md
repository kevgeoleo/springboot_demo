# React / Springboot demo project

## Steps to run

1. Step 1:

```
cd frontend
npm install
npm run dev
```

2. Step 2:

```
cd backend
.\mvnw.cmd spring-boot:run
```

3. Step 3:
   Visit `localhost:5173`
